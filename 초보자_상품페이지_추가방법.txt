WORLD PULSE에 상품 페이지 추가하기

1. 이 압축파일을 풉니다.
2. 기존 WORLD PULSE 폴더 안에 pages 폴더를 그대로 복사합니다.
3. 기존처럼 Streamlit을 다시 실행합니다.
4. 사이트 왼쪽 메뉴에 '상품 트렌드'가 자동으로 생깁니다.

처음에는 상품 트렌드 화면의 '데모로 보기'를 선택하면 됩니다.
실제 네이버 자료 연결은 Streamlit Cloud의 Settings > Secrets에 아래 두 줄을 입력합니다.

NAVER_CLIENT_ID="네이버에서 발급받은 값"
NAVER_CLIENT_SECRET="네이버에서 발급받은 값"

신상마켓·알리익스프레스·쿠팡의 실제 판매량은 화면의 'CSV 입력양식 받기'를 눌러
자료를 작성한 뒤 왼쪽 '판매자료 CSV'에서 업로드합니다.

휴대폰 앱 확장 순서
1단계: 지금 Streamlit 웹앱을 모바일 브라우저에서 사용
2단계: 홈 화면에 추가해 앱처럼 사용(PWA 형태)
3단계: 사용자가 늘면 FastAPI 서버 + Flutter 앱으로 분리
